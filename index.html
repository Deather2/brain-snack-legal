Brain Snack Uploader

A private upload tool for the Brain Snack YouTube channel, built on YouTube API Services.

Brain Snack Uploader is a private command-line tool used only by the owner of the Brain Snack YouTube channel.

It uploads short videos that the owner creates himself to his own YouTube channel, together with their titles, descriptions, tags, scheduled publish times and thumbnails, using the YouTube Data API.

The tool is not offered to the public and has no other users. It does not read, collect or store any data about other YouTube users.

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
