Privacy Policy

Last updated: October 7, 2026

Brain Snack Uploader ("the tool") is a private command-line application used only by its owner to upload videos to his own YouTube channel. This policy explains what data the tool accesses and how it is handled.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

The tool requests only the youtube.upload permission. It uses it to upload videos created by the owner, set their title, description, tags, privacy and scheduled publish time, and set their thumbnails. It does not read, collect, or analyze any data about other YouTube users, viewers, comments or analytics.

What data is stored

The tool stores, only on the owner's own computer:

  • the OAuth access token needed to upload to the owner's channel;
  • a local log of uploaded video IDs and their scheduled publish times, used to avoid duplicate uploads.

No data is sent to any server other than Google's, and no data is shared with or sold to third parties.

Revoking access

Access can be revoked at any time on the Google security settings page. Deleting the local token file also removes the tool's stored access.
